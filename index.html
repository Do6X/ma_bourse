Enregistrée automatiquement sur cet appareil (rien n'est envoyé ailleurs) — à saisir une seule fois par appareil. Pré-remplie avec le backend actuel par défaut.

Tout ce qui est saisi ici (valeurs suivies, séances, PEA, objectifs, dividendes...) reste uniquement sur cet appareil. Pour le retrouver ailleurs (ex. votre iPhone) : exportez un fichier ici, transférez-le vous-même (AirDrop, iCloud Drive, e-mail...), puis importez-le sur l'autre appareil.

⚠️ Importer un fichier remplace entièrement les données déjà présentes sur cet appareil (une confirmation vous sera demandée).

Pour chaque valeur, collez directement dans la case « Coller ici » la ligne correspondante copiée depuis la cote générale Boursorama (colonnes Dernier, Var., Ouv., +Haut, +Bas, Var. depuis le 1er janvier, Volume, séparées par des tabulations) — les colonnes se remplissent automatiquement dès le collage (le « (c) » à côté du cours de clôture est retiré automatiquement), corrigez si besoin, puis cliquez sur « Enregistrer tout » en bas du tableau. La date retenue est celle d'aujourd'hui pour toutes les valeurs.

Le « Var. » collé est indicatif : il est comparé à la variation recalculée automatiquement par le widget (à partir de votre dernière clôture enregistrée) et un écart notable est signalé après enregistrement, mais il ne remplace jamais ce calcul. Le volume est automatiquement converti en milliers.

Complète le tableau quotidien ci-dessus : celui-ci reprend, pour une valeur à la fois, le tableau « Historique 5 jours » copié directement depuis SA fiche Boursorama (5 jours en colonnes) — pratique pour rattraper toute une semaine en un seul collage par valeur plutôt que jour par jour. Pour chaque valeur listée ci-dessous, ouvrez sa fiche, copiez son tableau « Historique 5 jours » et collez-le dans la case correspondante : les colonnes se remplissent automatiquement (dates réelles comprises), corrigez si besoin, puis cliquez sur « Enregistrer cette semaine ».

Le « Var. » collé est indicatif, comme pour le tableau quotidien : il ne remplace jamais la variation recalculée automatiquement à partir de vos clôtures déjà enregistrées. Le volume est automatiquement converti en milliers.

Ce widget ne peut pas interroger une IA lui-même (pas de backend prévu pour ça) : ce bouton copie un résumé de toutes vos valeurs suivies (cours, objectif, consensus, position) suivi de votre question, prêt à coller dans une conversation avec Claude.

Prochaine publication de résultats et prochain versement de dividende, pour toutes vos valeurs suivies, triés par date la plus proche. Ces dates sont récupérées automatiquement par le backend quand son plan API les fournit — ce qui n'est actuellement pas le cas pour ces deux informations avec votre plan (quelle que soit la valeur, y compris américaine). Vous pouvez les renseigner vous-même dans le bloc « 📅 Agenda — saisie manuelle » de chaque fiche : une date saisie à la main prime alors toujours sur celle de l'API et apparaît ici marquée « (saisi) ». Vérifiez toujours la date exacte sur la fiche source avant d'agir en conséquence.

Complète le bouton « Copier pour vérification Boursorama » présent sur chaque fiche (qui ne concerne qu'une seule valeur) : celui-ci rassemble en un seul texte les consignes de contrôle pour TOUTES vos valeurs suivies, à coller en une fois dans votre conversation avec Claude plutôt que de le faire fiche par fiche.

Valeurs Euronext Paris : ajoutez le suffixe .PA (ex. MC.PA LVMH, TTE.PA TotalEnergies, OR.PA L'Oréal). Les fondamentaux/dividendes de ces valeurs peuvent rester indisponibles selon le plan API configuré côté backend — voir README.md.

Collez une liste de tickers et/ou de noms d'actions connus (un par ligne, ou séparés par des virgules) — ex. Alstom, LVMH, ALO.PA, TotalEnergies. Le lien Boursorama est pré-rempli automatiquement pour les valeurs Euronext Paris reconnues (à vérifier/corriger si besoin).
